# Map assets

Each directory is one map, and its name is the map's key. `map.json` and the
binary files are generated by the map's builder in `scripts/`
(`build-<map>.py`) from the definitions in `maps/`; `info.json` is written by
hand (menu name, description, base centres, blast dust colour). All geometry,
materials, terrain and ambient audio here are procedural PeakRunner assets.

These folders are the default maps. Installs carry them in `packs/maps/`
(`scripts/stage-packs.sh`, payloads compressed); the engine's catalog finds
them there, or here in a development build, and validates every checksum.
Nothing about a map is compiled into native builds (the browser build embeds
these folders). See `docs/map-pipeline.md` for authoring and verification,
and `docs/making-content.md` for adding maps without touching code.
